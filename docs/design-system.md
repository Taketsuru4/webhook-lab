# Webhook Lab interface

Adapted from the ui-ux-pro-max design-system search for a developer-tool dashboard. The search's event/conference landing pattern is not applicable; this product uses an inbox and inspector layout.

- Warm off-white canvas, restrained borders, orange primary action, muted green success states.
- IBM Plex Sans for interface text; JetBrains Mono for event identifiers and code. System font fallbacks work offline.
- Desktop workspace sidebar, endpoint strip, four factual metric cards, traffic histogram, inbox and request inspector.
- Mobile stacks inbox and inspector; sidebar becomes a compact top navigation.
- Lucide SVG icons, visible keyboard focus, modal focus management via native dialog, labeled controls, text accompanying status colors.
- Actual captured data only. Empty, loading, disconnected, filtered, and error states have explicit messages.
- Restrained color transitions; reduced-motion preference disables animation.
